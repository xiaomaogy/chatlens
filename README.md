# ChatLens

A **local-only** dashboard for your WeChat group chats. Sits on top of [`wechat-cli`](https://github.com/freestylefly/wechat-cli) and your local `claude` CLI — one click to generate a daily AI summary for any group, saved alongside that group's other 精华.

Inspired by [wesight.ai](https://wesight.ai) (the WeChat intelligence product) and [au12.net](https://au12.net) (the community-dashboard UX). Runs entirely on your laptop, never reaches a remote server.

## Why local-only?

- **Your data stays put.** WeChat messages never leave your machine — `wechat-cli` reads the local DB, the summary is generated by your local `claude` CLI, and everything is stored in `./data/chatlens.db`.
- **No API keys.** Summarization piggy-backs on the `claude` CLI's OAuth session (your Claude Max plan), via `claude -p` in subprocess mode.

## Quick start

```bash
cp .env.example .env
python3 -m pip install -e .
chatlens
```

That's it. The dashboard auto-opens at `http://localhost:8090`, syncs your group list from `wechat-cli`, and shows a "生成精华" button on every group card. Click it; 30–90 seconds later the summary appears in that group's 精华 list.

## Requirements

- macOS (where your local WeChat lives)
- Python 3.11+
- [`wechat-cli`](https://github.com/freestylefly/wechat-cli) — `pipx install wechat-cli && wechat-cli init`
- [Claude Code](https://claude.com/claude-code) — logged in with a Max plan

## How it works

```
┌────────────────┐    HTTP    ┌──────────────────┐
│ Browser at     │  ───────▶  │  FastAPI backend │ ──┬─ subprocess ─▶ wechat-cli (read history)
│ localhost:8090 │            │  + SQLite        │   └─ subprocess ─▶ claude -p (LLM summary)
└────────────────┘            └──────────────────┘
```

- `chatlens.wechat` — async wrapper around `wechat-cli sessions / history`
- `chatlens.llm` — spawns `claude -p` with a temp empty CWD; no API key, no SDK
- `chatlens.routers.groups` — list/sync groups
- `chatlens.routers.assets` — generate / list / view / delete summaries
- `chatlens.static/` — single-file SPA (Tailwind via CDN, hash-routed)

## Configuration

Everything is in `.env` (see `.env.example`). Defaults work for the standard install.

| Var | Default | Purpose |
|---|---|---|
| `HOST` | `127.0.0.1` | Loopback by design — local only. |
| `PORT` | `8090` | Dashboard port. |
| `WECHAT_CLI_PATH` | `wechat-cli` | Absolute path is safer. |
| `AUTO_OPEN_BROWSER` | `true` | Opens the dashboard tab on start. |
| `CLAUDE_PATH` | from `$PATH` | Override if `claude` isn't on PATH. |

## Packaging as a macOS app

Ship ChatLens as a native `.app` (WKWebView via `pywebview`, bundled with `py2app`):

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[build]"
./scripts/build_app.sh
# → dist/ChatLens.app
# → dist/ChatLens.dmg
```

The bundled app stores its SQLite DB and media under
`~/Library/Application Support/ChatLens/`. To override defaults (port,
`wechat-cli` path, etc.), drop a `.env` file in that directory.

### Sending to another Mac

The build is **unsigned** — on first launch macOS Gatekeeper will block it.
Tell the recipient one of:

1. Right-click `ChatLens.app` → **Open** → confirm the dialog. Once.
2. Or in Terminal: `xattr -dr com.apple.quarantine /Applications/ChatLens.app`

They still need `wechat-cli` and `claude` installed on their machine (see
**Requirements** above) — ChatLens does not bundle those.
